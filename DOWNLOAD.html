Formatador ABNT

Suplemento para Microsoft Word 2021/2024/365

🚀 Instalação Rápida

⬇️ Baixar Versão Mais Recente

⚠️ Requisitos

  • Microsoft Word 2021, 2024, 365 ou Word na Web
  • Windows 10 ou superior
  • Node.js (para desenvolvimento)
  • PowerShell (incluído no Windows)

📋 Instruções de Instalação

  1. Baixe o arquivo ZIP acima
  2. Extraia o conteúdo para uma pasta no seu computador
  3. Duplo-clique no arquivo ABNT.bat
  4. O Microsoft Word abrirá automaticamente com o suplemento carregado
  5. Na aba "Normas ABNT" no topo do Word, clique nas funcionalidades desejadas
